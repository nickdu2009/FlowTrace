#### 代码骨架修复（下午——技术方案审视）

**问题 1（严重）：包名路径不一致**
- 文件系统目录为 `com/myfiddler/`，但所有 `.kt` 文件 package 声明为 `com.flowtrace.*`
- 修复：将所有源码文件迁移到 `com/flowtrace/` 目录下，删除空的 `com/myfiddler/` 目录树

**问题 2（严重）：`settings.gradle.kts` 内容重复**
- `pluginManagement`/`dependencyResolutionManagement`/`include` 各出现两次
- 修复：去重，保留一份

**问题 3（严重）：`WsDirection` 枚举重复定义**
- `CaptureEvent.kt` 和 `SessionModels.kt` 各自定义了 `WsDirection`，类型不互通
- 修复：统一定义到 `domain.model.Identifiers.kt`，两处改为 import 引用

**问题 4（严重）：`CaptureEngine.kt` 中 `SessionId` import 错误**
- 错误地 import `com.flowtrace.domain.session.SessionId`，实际定义在 `domain.model`
- 修复：改为 `import com.flowtrace.domain.model.SessionId`

**问题 5（中等）：缺少 ADR-0003 承诺的端口接口**
- 新增 `BodyStorePort`（`domain/session/BodyStorePort.kt`）：Body 分离存储端口
- 新增 `ClockPort`（`domain/model/ClockPort.kt`）：时间源端口，便于测试与一致性
- 新增 `SessionAggregator`（`domain/capture/SessionAggregator.kt`）：会话聚合器端口，幂等合并、乱序容忍、批处理友好
- 新增 `CaptureState`（`domain/capture/CaptureEngine.kt`）：VPN 抓包状态机枚举（Idle/Starting/Running/Stopping/Error）

**问题 6（中等）：HTTP Headers 用 `Map<String, String>` 建模，丢失重复 header**
- HTTP 规范允许同名 header 多次出现（典型如 `Set-Cookie`）
- 修复：`CaptureEvent`、`SessionModels`、`Redactor` 中的 headers 统一改为 `List<Pair<String, String>>`

**问题 7（轻微）：缺少 Timing 结构化模型**
- 新增 `Timing`（`domain/capture/Timing.kt`）：dns/connect/tls/ttfb/download 分阶段耗时
- `HttpResponseCompleted` 和 `SessionDetail` 中新增 `timing: Timing?` 字段

## 补充：Java 25 + Kotlin 2.3.0 构建打通（夜间）

### 背景
- 目标：在 **不降级系统 JDK（Java 25.0.1）** 的前提下，让 Android 工程可稳定构建。

### 结论
- ✅ 使用 **Gradle Wrapper 9.1.0 + Kotlin 2.3.0** 可在 **Java 25** 下正常执行构建（至少 `assembleDebug`）。
- ✅ Hilt 在 Kotlin 2.3.0 下需要升级并显式处理 kotlin metadata 版本。

### 关键变更
- 构建工具链：
  - Gradle Wrapper：`8.5` → `9.1.0`（支持 Java 25）
  - Kotlin：`2.0.21` → `2.3.0`
  - Compile SDK：`34` → `35`（满足 androidx 依赖要求）
- Kotlin 编译策略：
  - `android/gradle.properties` 增加 `kotlin.compiler.execution.strategy=in-process`
  - 目的：避免 Kotlin compile daemon 在 Java 25 下初始化时的版本解析异常
- Hilt / Dagger：
  - 升级 Hilt：`2.54` → `2.57.2`
  - `app` 模块显式添加 `org.jetbrains.kotlin:kotlin-metadata-jvm:2.3.0`（用于 Hilt 解析 Kotlin 2.3 metadata）
- 小修复：
  - 修复 `Rules.kt` 注释中 `text/*` 导致的解析异常（改为 `text/ *` 表达“任意子类型”）

### 验证
- ✅ `./gradlew :core:domain:compileKotlin`
- ✅ `./gradlew :app:hiltJavaCompileDebug`
